# Mục Lục Tài Liệu Nội Bộ

Đây là điểm vào nhanh cho toàn bộ tài liệu vận hành và kiến trúc của repo `Tomato_Downloader`.

## Danh Sách Tài Liệu

- [Tổng kết dự án](./project-summary.md)
- [Kiến trúc backend](./backend-architecture.md)
- [Luồng job tải và dịch](./job-flow.md)
- [Sơ đồ module và phụ thuộc](./module-dependency-map.md)
- [Quy trình deploy](./deploy-process.md)
- [Sổ tay vận hành server](./server-runbook.md)

## Cách Đọc Nhanh

1. Đọc `project-summary.md` để nắm toàn cảnh dự án.
2. Đọc `backend-architecture.md` nếu cần hiểu luồng request, storage, và hạ tầng.
3. Đọc `job-flow.md` nếu cần nắm vòng đời job.
4. Đọc `module-dependency-map.md` nếu cần sửa code hoặc refactor.
5. Đọc `deploy-process.md` và `server-runbook.md` nếu cần deploy hoặc restart server.

## Ghi Nhớ

- Tài liệu này ưu tiên tiếng Việt có dấu để AI agent sau này đọc thống nhất.
- Thuật ngữ kỹ thuật như `API`, `SQLite`, `SSE`, `STV`, `Legacy` được giữ nguyên khi cần.
